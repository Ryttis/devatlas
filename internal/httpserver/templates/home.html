DevAtlas shows only projects you register explicitly. Register an existing directory as the first checkout of a project from a terminal:

devatlas add -project my-project -name "My Project" /path/to/checkout
  • -project is a stable ID you choose: lowercase letters, digits, and hyphens.
  • -name is the display name; it is required only for a new project.
  • Run the command again with the same -project to add more checkouts or worktrees.

Registration only writes the DevAtlas registry file; the directory is never modified. Reload this page afterwards. devatlas list shows the same registrations in the terminal.
